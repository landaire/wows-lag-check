Glossary

Gap
Time between consecutive server ticks. Above the threshold = spike.
Since prev
Quiet time since the last spike (MM:SS:mmm).
Peak ping
Highest ping in the gap window plus a 2s tail.
Server-only
Client packets kept flowing during the gap; server stalled.
Client+server
Client packets dried up too. Full freeze.
Battle time
Clock relative to match start. Exact with entity defs, otherwise approximated (30s countdown).
